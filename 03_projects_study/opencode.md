# OpenCode 开源 Agent 研读笔记

> **项目链接**: [anomalyco/opencode](https://github.com/anomalyco/opencode)

## 📌 项目概述
OpenCode 是一个开源的终端 AI Coding Agent 工具与 Harness 架构探索项目。

## 🎯 核心特性与架构要点
- **终端交互模式**：类似 Claude Code / Codex CLI，直接在终端中响应用户指令。
- **环境上下文管理**：集成终端执行、文件树读写与上下文压缩能力。
